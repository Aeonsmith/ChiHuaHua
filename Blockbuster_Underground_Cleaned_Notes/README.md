## 🔍 Search & Filtering Architecture

The application UI includes a multi-scope, tokenized search engine:

### 1. Scope Selector
- **`All`**: Scans titles, tags, and full body content across all notes.
- **`🏷️ Tags`**: Restricts matching exclusively to metadata tags.
- **`📄 Content`**: Deep full-text search across raw markdown and cleaned content.

### 2. Tag Prefix Shortcut (`#`)
- Typing `#` followed by a keyword (e.g., `#sovereignty`, `#ford-bronco`, `#bipolar-bear`, `#raptor`) automatically routes the query to tag-specific matching.

### 3. Interactive Tag Pills
- Every note card displays interactive tag pills. Clicking any `#tag` pill in the UI immediately applies a tag filter across the vault.

### 4. Multi-Token Tokenized Search
- Space-separated keywords (e.g. `2021 model year`, `raptor suspension`, `air gapped iso`) match across headers and body paragraphs regardless of sentence placement.

### 5. Fast Filter Chips & Section Sub-Nav
- Instant one-click filter chips for `🚙 Ford Bronco`, `🔔 Bi-Polar Bear`, `🛡️ Sovereign ISO`, and `🧅 Tor Onion`.
- In-document generation jumper for the Ford Bronco documentation (`Gen 1` through `Gen 6`, `Concepts`, `Market Dynamics`).

## 🛠️ Installation & Running

### Prerequisites
- Python 3.10+ (Standard library only; zero third-party pip dependencies required).
- Optional: Tor Browser / Tor daemon for active onion routing.

### Quick Start
1. **Desktop Launcher:** Double-click `Blockbuster Underground Notes.bat` or `.lnk` on the Desktop.
2. **Terminal:**
   ```bash
   cd C:\Users\ole_a\Desktop\Blockbuster_Underground_Cleaned_Notes
   python app.py
   ```
3. Open your browser at `http://localhost:7890`.
